**Todo lo que hace Claupet, paso a paso.** Versión 2.5.0.

Claupet vive junto al reloj y le cuenta, sin abrir una terminal, cuánto le queda de su plan de Claude
Code, qué sesión le necesita y en qué anda cada una. Este manual explica cómo instalarla, cómo se usa
cada parte y qué hace cada ajuste. Si es su primera vez, empiece por
[Instalar Claupet](es/instalar.md) y siga con [Primeros pasos](es/primeros-pasos.md).
