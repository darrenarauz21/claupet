# Claupet manual

**Everything Claupet does, step by step.** Version 2.5.0.

---

Claupet lives next to the clock and tells you, without opening a terminal, how much of your Claude Code
plan is left, which session needs you and what each one is up to. This manual explains how to install it,
how each part works and what every setting does. If it's your first time, start with
[Install Claupet](instalar.md) and continue with [Getting started](primeros-pasos.md).
